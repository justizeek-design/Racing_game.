# Racing_game.

NEON DRIFT: TOKYO RUSH is a browser-based arcade racing game built with HTML5 Canvas, CSS, and JavaScript.

## Play

Open `Racing_game.html` in a modern browser. On a phone, serve the folder over your local network and open `Racing_game.html?play=mobile` to use the touch controls.

Desktop controls: WASD or arrow keys to steer and accelerate, Space to drift, and Shift for nitro.
